# 光学折射实验室（Optics Lab）

一个运行在浏览器里的 **二维几何光学折射模拟器**：可以自由摆放不同形状、不同折射率的玻璃元件，
用单色或复色（色散）光源发射单束 / 多束光线，实时看到折射、反射、全反射与彩虹色散。

**零依赖**：没有 npm 依赖需要安装。

浏览器实际加载的是 **`dist/` 里的纯 JavaScript 版本**（由 `src/` 的 TypeScript 自动生成），
因此**对浏览器版本没有特殊要求**（普通现代浏览器即可，不需要 Chrome 111+ 那种原生类型剥离能力）。

> 修改 `src/` 后要让浏览器生效，运行一次 `npm run build` 重新生成 `dist/`。

## 怎么打开（手把手）

项目目录是 **`D:\sxzcode\harness`**。因为这是一个网页，需要一个静态服务器把它“端”给浏览器
（直接双击 `index.html` 用 `file://` 打开**不行**，浏览器会拦住 ES module 的跨源加载）。

### 最省事的办法：双击 `start.cmd`

在项目文件夹里双击 **`start.cmd`**，它会自动切到项目目录、检查端口、启动服务器，并帮你打开浏览器。
关掉那个黑色窗口就是停止服务。

> `start.cmd` 内部刻意只使用 **纯 ASCII 字符**：cmd.exe 是按系统 ANSI 码页（简体中文是 GBK）
> 读取批处理文件的，如果里面写中文，就会变成 `'鍔ㄥ垏鍒拌剼鏈墍鍦ㄧ洰褰�' 不是内部或外部命令`
> 这类乱码报错。若你想改成中文提示，请在文件开头加 `chcp 65001 >nul` 并把文件保存为
> **UTF-8 无 BOM**，或者干脆保持英文。

### 手动启动（三步）

`node server.mjs` 只在**当前目录**里找文件。如果你在别处（比如 `C:\Users\admin`）执行，就会看到
`Error: Cannot find module 'C:\Users\admin\server.mjs'` —— 所以第一步必须先切换目录：

#### 第 1 步：进入项目目录

```powershell
# PowerShell / CMD
cd /d D:\sxzcode\harness
```

```bash
# Git Bash / WSL
cd /d/sxzcode/harness
```

> 如果 `D:` 盘不存在或路径不同，请把命令里的路径换成你实际存放项目的位置。
> 提示：在文件资源管理器里打开项目文件夹，地址栏输入 `cmd` 回车，就能直接开在这个目录下。

#### 第 2 步：启动服务器

```powershell
node server.mjs
```

成功时终端会打印：

```
光学折射实验室 → http://127.0.0.1:5180/
静态根目录: D:\sxzcode\harness
```

**保持这个窗口开着**（关掉窗口 = 关掉服务器）。默认端口 5180，被占用时可以换：

```powershell
node server.mjs --port 5200
```

#### 第 3 步：在浏览器里打开

在 Chrome / Edge 的地址栏输入（或按住 Ctrl 点击链接）：

**http://127.0.0.1:5180/**

看到深色界面、左侧参数面板、中间出现光线，就成功了。

#### 第 4 步：关闭

在服务器窗口按 `Ctrl + C`。

### 如果打开后是“一片黑、什么都没有”

页面内置了三层自我保护，会把问题直接写在画布上方（红底提示框），**不需要打开 DevTools**：

1. **模块没跑起来**（浏览器不支持原生 TS 类型剥离、或脚本 404/被拦）：
   画布上会长期停留「正在启动…（若这行文字在 2 秒后仍然存在…）」。
2. **渲染循环抛异常**：会显示 `⚠ 渲染循环出错` 以及完整调用栈；而且循环不会中断，后续帧会继续尝试。
3. **布局异常**（画布量不到尺寸）：会显示 `⚠ 布局出错` 并给出 `rect / canvas.width / clientWidth / offsetParent` 的具体数值；
   同时顶栏「帧时」读数会带上 `画布 宽×高`，并在出错时追加 `⚠ N 个错误`。

把提示框里的文字发给我就能定位。也可以按 `F12` 打开控制台，搜索 `[光学折射实验室]` 前缀的日志。

## 物理模型

全部计算都是逐条光线、逐个界面的**矢量形式几何光学**，没有任何“假造的彩虹”。

### 1. 折射（斯涅尔定律，矢量形式）

无全反射时，界面法线 `n` 指向入射侧，`cosθᵢ = −n·d`，`η = n₁/n₂`：

```
cosθₜ = √(1 − η²(1 − cos²θᵢ))
t = η·d + (η·cosθᵢ − cosθₜ)·n
```

根号内为负即发生**全反射**（此时不产生透射光线）。

### 2. 反射

```
r = d − 2(n·d)·n
```

### 3. 分光（菲涅耳公式，非偏振光）

```
Rs = |(n₁cosθᵢ − n₂cosθₜ)/(n₁cosθᵢ + n₂cosθₜ)|²
Rp = |(n₁cosθₜ − n₂cosθᵢ)/(n₁cosθₜ + n₂cosθᵢ)|²
R = ½(Rs + Rp),   T = 1 − R
```

界面处光线按 `R` / `T` 分裂为两支，**能量严格守恒**（忽略吸收），因此玻璃表面的“鬼影反射”
和多次反射都是算出来的。全反射时 `R = 1`、`T = 0`。
正入射时退化为 `R = ((n₁−n₂)/(n₁+n₂))²` —— 空气→ `n=1.5` 玻璃约为 4%。

### 4. 色散（Cauchy + Abbe）

```
n(λ) = n_d + B·(1/λ² − 1/λ_d²)
B = (n_d − 1) / (V_d·(1/λ_F² − 1/λ_C²))
```

* `n_d`：587.6nm（氦 d 线）下的折射率，即面板上的「折射率」滑杆。
* `V_d`：阿贝数，越小色散越强（火石玻璃）；面板可设为「无色散」（所有波长同折射率）。
* 参考波长取自氢 F 线 486.1nm、C 线 656.3nm。

复色光被拆成若干单色光**分别追踪**，最后在同一张线性强度缓冲里做加性叠加，
所以「多色重叠处变白、棱镜后展开成彩虹」是计算结果，不是贴图。

### 5. 介质判定

每个交点处，沿光线反方向退极小距离取探针点，判断它是否落在多边形内部，
从而决定 `n₁`、`n₂`。因此重叠、嵌套的元件也不会判错“进入/离开”。

### 6. 折线近似

圆弧面按 48 段折线离散（弦高误差 < 0.1%），每条边在世界坐标下都是精确直线；
每条光线在元件之间都是直线段，这一点在测试里有显式断言。

## 画布操作（平移 / 缩放）

| 操作 | 效果 |
| --- | --- |
| **左键拖动空白处** | 平移画布（光标会变成「可移动」样式） |
| **滚轮** | 以**光标位置为锚点**缩放画布（光标下的内容不会跑掉） |
| 中键拖动 / 右键拖动 / 空格 + 拖动 | 平移画布（任何位置都可用） |
| 双击空白处 / `Ctrl+0` | 复位视图（中心 + 100% 缩放） |
| 面板「视图」区 | 复位视图 / 适应场景 / 放大 / 缩小 |

缩放范围 15% ~ 1200%，顶栏「帧时」读数会实时显示当前**缩放百分比**与**视图中心坐标**。
平移缩放只改变观察方式，不修改任何元件参数；光线按当前可见范围重新追踪，
所以放大后能看到更远的光路（窗口外的部分本来就不绘制）。

> `Shift` + 滚轮 = 缩放**元件尺寸**（不是缩放画布）。

## 渲染管线

1. 所有线段以 `lighter`（加性）画进一张**低分辨率追踪缓冲**，颜色固定、亮度由该段携带的光强决定；
2. 缓冲放大到显示层，并叠加 2 层模糊做光晕、1 层对比度压缩提亮高光，最后加轻微暗角；
3. 最上层绘制网格（间距随缩放自适应）、元件轮廓、法线、拖拽手柄与光源示意。

背景采用偏亮的深蓝灰渐变（`#1b2740 → #121a2b`），既保留光线的对比度，又不会显得「一片黑」。

拖动时分辨率自动降档（约 55%），松手 140ms 后恢复到设定值。

## 实现说明与已知限制

### 验证状态

- 物理内核、斯涅尔/菲涅耳自洽性、场景预设、界面端到端（DOM 打桩）共 **48 项断言全部通过**，
  由 `npm test` 一次跑完。
- 界面部分通过 `test/dom-stub.ts` 在 Node 里真实执行：面板构建、追踪、渲染一帧、
  点击选中、拖动元件/光源、滚轮缩放、删除、撤销/重做、导出等路径都会被走到。
- **未在真实浏览器里截图验证**：开发环境的沙箱禁止 Chromium 启动所需的命名管道，
  无头浏览器无法运行。首次在浏览器中打开时请留意控制台是否报错。

### 其它

- **2D 截面模型**：正确的斯涅尔定律在二维子午面上的应用，不是三维渲染的近似。
- **强度模型**：界面处按菲涅耳分裂并逐段累加，不做吸收衰减（没有 Beer–Lambert 项）。
- **偏振**：只计算非偏振光的平均反射率，不追踪 s/p 分量。
- **干涉/衍射**：不做波动光学，因此看不到牛顿环、艾里斑等效果。
- **圆弧离散化**：圆弧以 48 段折线参与求交，掠射到弧面上会有微小误差。
- **性能安全阀**：线段数与求交次数都有上限，达到上限时状态栏会提示「已达上限」。
- **浏览器要求**：需要支持原生 TypeScript 类型剥离的浏览器（Chrome/Edge 111+）。
  若用旧浏览器打开，页面会给出明确提示而不是白屏。
